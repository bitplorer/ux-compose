# Start here — Pulseboard

```bash
pip install -e ".[dev]"          # from the ux-compose repo, Python ≥ 3.14
make pulseboard                  # http://127.0.0.1:8080
```

Press **A sale lands** on the KPI strip. Drag a deal **To Negotiate**.
Filter the timeline. Flip presence. **Close quarter** mints a Cap.
**Wipe board** is refused unless the host mints `admin.reset`.
